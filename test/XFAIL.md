## AI project catalog (@-reference) — supersedes the switchboard (2026-07-08)

The active-project switchboard (2026-06-11) was replaced by a taught `@<name>`
project **catalog**. The extension publishes a flat catalog of ALL registered
projects — the same body in `<triforgeDir>/AGENTS.md`, `CLAUDE.md`, and
`.github/copilot-instructions.md` (so whichever file a given AI tool auto-loads
carries the catalog) — regenerated on `project:listChanged`. Each row maps a
project's `@`-reference (folder basename) → absolute path → one-line summary;
`projects.json` is named the authoritative live list. The Triton home is seated as
`workspaceFolders[0]` once per empty-window session (consent-gated); `triforge.openHome`
seats it on explicit request, and a one-time non-modal notification offers to do so
when the catalog isn't visible. All active-project steering was removed.

| Area | Suite | Status |
| --- | --- | --- |
| Catalog renderer | `test/unit/services/renderCatalog.test.ts` — marker, `@`-convention preamble (incl. the no-match / re-read-`projects.json` rule), one row per project, empty-state, `cell()` pipe/newline/backtick escaping, no `apiKeys` leak, `summarizeProject` | **green** |
| Control-root helpers | `test/unit/services/controlRoot.test.ts` — `.triforge` resolution, pure `samePath` (win32 case-fold), and the seat-plan decision (`seat-empty-window` / `already-seated` / `leave-nonempty`) | **green** |
| Catalog E2E | `test/e2e/suites/ai/catalog.e2e.test.ts` (2) — all registered projects listed with `@`-refs + absolute paths in all three catalog files; provenance guard preserves a user-authored `.triforge/AGENTS.md` | **green** |

Seating + the seat reload are **not** E2E-asserted: the empty ExTester window cannot
survive the consent modal or the host reload, so the E2E harness defaults
`aiProjectFocus: 'disabled'` (`setExtensionWorkspacePath` in `test/e2e/helpers/seed.ts`)
and the catalog E2E asserts only the reload-free file writes. The seat **decision** is
covered by the pure `planControlRoot`/`samePath` unit tests; the seat action is verified
manually.
